# 📺 Netflix Series Tracker Dashboard

## Overview

This project is an interactive Microsoft Excel dashboard designed to analyze Netflix series viewing patterns.

The dashboard provides insights into ratings, genres, watch hours, completion status, and monthly viewing trends using Pivot Tables, Pivot Charts, and Slicers.

## Features

- Interactive Slicers
- Top 10 Highest Rated Series
- Monthly Watch Hours
- Watch Hours by Genre
- Series Completion Status
- Key Insights Section
- Dynamic Pivot Charts

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

---

## Key Insights

- Completed Series: 61%
- Highest Watch Hours: June
- Most Watched Genre: Romance
- Highest Rating: 9.80
- Average Rating: 8.20
